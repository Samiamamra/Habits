# عادات / Habits — v2

مصدر واحد (`www/`) يعمل كموقع وتطبيق حاسوب وتطبيق هاتف. هذا الدليل يشرح
بناء النسختين **دون تثبيت Android Studio أو Electron على جهازك** — البناء
يتم في سحابة GitHub المجانية، وأنت تنزّل الملف النهائي فقط.

## 1) ضع المشروع على GitHub (مطلوب للبناء السحابي وللاستضافة)

لا حاجة لأوامر Git. من المتصفح:
1. أنشئ حسابًا مجانيًا على github.com إن لم يكن لديك.
2. اضغط **New repository**، سمّه مثلًا `taskhabit`، اختر **Private** إن أردت، ثم **Create repository**.
3. افتح مجلد `taskhabit` الذي فككت ضغطه على جهازك، وادخل إلى صفحة المستودع على GitHub، اضغط **Add file → Upload files**، ثم اسحب **كل محتويات المجلد** (وليس ملف zip نفسه) وأفلتها، وانتظر الرفع ثم اضغط **Commit changes**.
   - الحجم صغير جدًا (بضع مئات من الكيلوبايت)، فهذه الخطوة مناسبة حتى مع إنترنت بطيء.

## 2) بناء تطبيق الهاتف (APK) بلا Android Studio

1. في مستودعك على GitHub، افتح تبويب **Actions**.
2. اختر **Build Android APK** من القائمة الجانبية، ثم اضغط **Run workflow** (زر أخضر) ← **Run workflow** للتأكيد.
3. انتظر 5–10 دقائق حتى يكتمل (دائرة خضراء ✓). كل البناء يتم على خوادم GitHub، لا شيء يُحمَّل على جهازك.
4. افتح التشغيل المكتمل، وفي أسفل الصفحة ستجد **Artifacts → taskhabit-android-debug-apk**. نزّله (ملف صغير عدة ميغابايت فقط).
5. فُك ضغط الملف، انقل `app-debug.apk` إلى هاتفك (عبر رابط تنزيل أو كابل)، فعّل "السماح بالتثبيت من مصادر غير معروفة"، وثبّته.

هذا APK حقيقي يعمل بكل الميزات (التذكيرات، المزامنة، إلخ)، لأنه بُني من مشروع Capacitor الفعلي. لبناء نسخة موقّعة لنشرها على Google Play لاحقًا، أخبرني وسأشرح خطوة التوقيع (keystore).

## 3) بناء تطبيق الحاسوب بلا تثبيت Electron محليًا

1. نفس تبويب **Actions**، اختر **Build Desktop Apps**، ثم **Run workflow**.
2. يُبنى تلقائيًا لثلاثة أنظمة معًا (Windows / macOS / Linux) على خوادم GitHub.
3. بعد الاكتمال، نزّل الـ Artifact المناسب لنظامك: `taskhabit-desktop-windows-latest` (exe)، `-macos-latest` (dmg)، أو `-ubuntu-latest` (AppImage).
4. على macOS قد يظهر تحذير "مطوّر غير معروف" لأن التطبيق غير موقّع؛ اضغط بزر الفأرة الأيمن ← Open لتجاوزه.

## 4) استضافة الحسابات والمزامنة (مجانًا وبشكل دائم)

نستخدم **MongoDB Atlas** (قاعدة بيانات مجانية إلى الأبد، بلا بطاقة بنكية) لحفظ
الحسابات والبيانات، و**Render** (استضافة مجانية للخادم) لتشغيله. هذا المزيج
موثوق لأن البيانات لا تُفقد عند إعادة التشغيل، خلافًا لتخزين الملفات المحلي
على استضافات مجانية أخرى.

### أ) إنشاء قاعدة بيانات مجانية (MongoDB Atlas)
1. سجّل في mongodb.com/cloud/atlas مجانًا (بريد إلكتروني فقط).
2. أنشئ Cluster مجانيًا بنوع **M0 Free**.
3. من **Database Access**: أنشئ مستخدم قاعدة بيانات (اسم وكلمة مرور، احفظهما).
4. من **Network Access**: أضف عنوان **0.0.0.0/0** (يسمح بالاتصال من أي مكان، لازم لأن Render لا يملك IP ثابتًا).
5. من **Connect → Drivers**، انسخ رابط الاتصال (يشبه `mongodb+srv://user:<password>@cluster0.xxxxx.mongodb.net/`)، واستبدل `<password>` بكلمة مرورك الحقيقية.

### ب) تشغيل الخادم مجانًا (Render)
1. سجّل في render.com (يمكن بحساب GitHub مباشرة، بلا بطاقة بنكية للخطة المجانية).
2. اضغط **New + → Blueprint**، واختر مستودع `taskhabit` الذي رفعته. سيكتشف Render ملف `render.yaml` تلقائيًا ويهيّئ كل شيء.
3. عند السؤال عن `MONGODB_URI`، الصق رابط الاتصال من الخطوة السابقة.
4. اضغط **Apply/Deploy**. بعد دقيقة أو دقيقتين سيعطيك Render رابطًا مثل:
   `https://taskhabit-server-xxxx.onrender.com`

هذا الرابط هو أيضًا **نسخة الموقع الإلكتروني** كاملة (الخادم يخدم الواجهة
نفسها). افتحه مباشرة لتجربة النسخة على الويب.

### ج) ربط تطبيقي الحاسوب والهاتف بالخادم
في التطبيق: **الإعدادات ← الحساب والمزامنة**، أدخل رابط Render في حقل "عنوان
الخادم"، ثم أنشئ حسابًا أو سجّل الدخول. في نسخة الموقع اترك الحقل فارغًا (لأنه
يخدم نفسه تلقائيًا).

**ملاحظة عن الخطة المجانية في Render:** يتوقف الخادم بعد ~15 دقيقة من عدم
الاستخدام، وأول طلب بعده يستغرق نحو 30–50 ثانية ليستيقظ (الطلبات التالية
سريعة). هذا لا يفقد أي بيانات لأنها محفوظة في MongoDB، فقط تأخير بسيط عند
أول استخدام بعد فترة خمول.

## بديل أسرع للهاتف بلا GitHub إطلاقًا (اختياري)

إن أردت تجربة سريعة جدًا: بعد تشغيل الخادم على Render (الخطوة 4)، اذهب إلى
**pwabuilder.com**، الصق رابط موقعك، واضغط لتوليد حزمة أندرويد. هذه الطريقة
أبسط لكنها تعتمد على متصفح مضمّن (Trusted Web Activity) بدل تطبيق أندرويد
أصلي كامل، والتذكيرات فيها أقل موثوقية من نسخة GitHub Actions أعلاه.

## ملاحظات عامة
- خط IBM Plex يُحمَّل من الإنترنت؛ دونه يستخدم التطبيق خط النظام.
- التذكيرات: في الموقع/الحاسوب تعمل والتطبيق مفتوح؛ على الهاتف تُجدول إشعارات محلية لـ14 يومًا قادمة عبر Capacitor، تعمل حتى والتطبيق مغلق.
- كلمات المرور تُخزَّن مشفّرة (scrypt)، والاتصال عبر Render يكون HTTPS تلقائيًا.
- لتشغيل الخادم محليًا على جهازك للتجربة فقط: `npm run server` (يحفظ البيانات في ملفات JSON محلية إن لم تضبط `MONGODB_URI`).
